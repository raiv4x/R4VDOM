# Qué es ? 

Es una vulnerabilidad en **Sistemas Windows**. Los principales sistemas afectados son:

	- Windows 7
	- Windows Vista
	- Windows 8.1
	- Windows Server 2003
	- Windows Server 2008
	- Windows Server 2012

EternalBlue es una vulnerabilidad en Windows que permite a un atacante entrar a una computadora sin usuario ni contraseña, solo por estar conectada a la red.

**CVE-2017-0144**
