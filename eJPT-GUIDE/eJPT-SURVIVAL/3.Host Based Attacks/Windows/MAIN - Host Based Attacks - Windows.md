# Qué son? 

Son ataques que se realizan **directamente contra un host Windows**, una vez que:

- Ya se descubrió el equipo
- Ya se identificaron servicios
- Ya se encontró una posible vía de entrada

No atacas “la red”, atacas **la máquina**
