# Qué es? 

Una **shell** es una **interfaz para ejecutar comandos del sistema operativo**.

Normalmente:

- Usuario → teclado → shell → sistema

En Hacking:

> Una shell es **acceso remoto a la ejecución de comandos** en la máquina víctima

Generalmente **para ganar acceso a una shell** ejecutaremos la herramienta **[[Netcat]]**

# Tipos de Shells

Cuando se logra ejecutar comandos en algún sistema, **casi siempre lo que prosigue es ganar una shell**. Es decir, ganar una sesión interactiva con el dispositivo para poder interactuar directamente con él. 

- **[[Bind shells]]**
- **[[Reverse shells]]**
