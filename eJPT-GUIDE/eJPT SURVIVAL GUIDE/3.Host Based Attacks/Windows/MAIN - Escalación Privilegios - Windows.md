# Qué es? 

**Escalación de privilegios en Windows** es el proceso mediante el cual un atacante que **ya tiene acceso al sistema** (normalmente como un usuario de bajos privilegios) logra **obtener permisos más altos**, idealmente **Administrador** o **SYSTEM**.
